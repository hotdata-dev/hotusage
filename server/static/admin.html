Override database
An organization's database is its isolation. Repointing one changes where its dashboard reads and where its collectors' usage lands. Rows already reported stay in the old database and disappear from the dashboard — nothing is moved or copied. A database with no usage tables gets them on save. An id already claimed by another organization is refused: one database per organization is the only thing keeping their data apart.
